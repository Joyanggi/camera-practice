# camera-practice

리코 GR IV(28mm 고정)로 빛 · 거리 · 구도를 익히는 수련표. 주소만 알면 폰에서도 바로 열린다.

**바로 가기 → [joyanggi.github.io/camera-practice](https://joyanggi.github.io/camera-practice/)**

| 페이지 | 용도 |
|---|---|
| [28mm 여덟 주](https://joyanggi.github.io/camera-practice/compact.html) (압축판) | 한 주에 개념 하나·과제 하나, 필수 영상 11편, 책 한 권, 카메라 규칙 한 줄. 여기서 시작한다. |
| [28mm 수련표](https://joyanggi.github.io/camera-practice/training.html) (원본) | 영상 31편 자막 전수 검증, GR IV 유저 모드(U1/U2/U3) 세팅, 현장 카드, 덜어내기 세 도구, 대표 사진 링크. 자료실과 매뉴얼. |

## 구조

- 순서는 제임스진 「사진 공부 이 순서로 하면 거의 실패합니다」의 **빛 → 거리 → 구도 → 설정 → 장비**.
- 영상은 전부 자막을 내려받아 처음부터 끝까지 대조했고, 긴 영상은 "볼 곳" 구간을 표시했다. 설명이 틀렸던 곳은 각 영상에 "정정"으로 남겨 두었다.
- GR IV 세팅은 한국어 사용설명서(메뉴 목록·조작표·Fn 버튼 설정)로 항목명과 동작을 확인했다.
- 체크 표시는 브라우저 `localStorage`에만 저장된다. 기기가 바뀌면 처음부터다.
